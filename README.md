## 📌 About SoulTalk

SoulTalk is an AI-powered mental wellness companion designed to provide emotional support through natural conversations. It helps users express their feelings, track moods, receive motivational guidance, and practice mindfulness in a comfortable and judgment-free environment.

The main vision behind SoulTalk is to make emotional support more accessible using Artificial Intelligence while maintaining a friendly and human-like experience.

## 🚀 Installation

1. Clone the repository

```bash
git clone https://github.com/Aish-369/SoulTalk---AI-Based-Mental-Health-Support-Chatbot.git
```

2. Open the project in Android Studio

3. Configure Firebase/API keys

4. Build and run the application
